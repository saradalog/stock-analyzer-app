# 銘柄分析アプリ

日本株の銘柄分析（業績10年推移・収益性/効率性/安全性・EV/EBITDA・営業利益/EV・残余利益モデル・DCF法・競合比較）をスマホで見るWebアプリ（PWA）。GitHub Pages で配信し、ホーム画面に追加して使う。

- このリポジトリには画面のコードだけを置いている。銘柄データは、Googleスプレッドシートに付けた Apps Script から合言葉を知っている人だけが取得できる。
- データは非公開リポジトリ（analysis）の GitHub Actions が平日19:37に作る。毎日更新するのは保有銘柄と独自予想のある銘柄だけで、ほかの銘柄は分析したいときにコードを指定して追加する（全上場銘柄を毎日計算する方式はやめた）。
- 画面のコードはこのリポジトリだけにある。他のAIで編集するときは `AGENTS.md` を読ませる。
